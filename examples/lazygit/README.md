# LazyVue

A lazilygit-inspired terminal UI built with Vue 3 and `vue-termui`. It is an
interactive, in-memory repository demo: stage files, switch branches, create a
commit, push, pull, and inspect the command log without modifying the real
working tree.

Requires Node.js 26.3 or newer.

```bash
pnpm --filter @vue-termui/example-lazygit dev
```

Build and run it with:

```bash
pnpm --filter @vue-termui/example-lazygit play
```

Press `?` in the app for the complete keyboard map.
