# Vue Ranger

A read-only file manager with text, image, and metadata previews.

```bash
pnpm --filter @vue-termui/example-file-manager dev
```

Use arrows or `hjkl` to navigate, Enter to open, Backspace to go up, `h` to
toggle hidden files, and `q` to quit. Paths are resolved below the directory
where the app was started; this example never writes or deletes files.
